Pressure system

Steady pressures and flows on the coupled liver vascular trees (trees/pressure.jl)

Mariia Myshkina, Matthias König

2026-11-28

The question

What do we have?

  • 4 trees: inflow A, P, outflow V, B (<tree>.arrow)
  • per edge \(k=(i,j)\): diameter \(d_k\), length \(l_k\), ODE group, predecessors / successors
  • known pressures at the tree roots: A 80, P 10, V 3, B 4 mmHg

→

How?

  • every edge is a Poiseuille tube: flow \(\propto\) pressure difference
  • mass conservation at every node → one linear equation per edge
  • boundary rows: inflows \(Q\), pressure drops, common terminal pressure
  • one sparse linear system \(A\,x = b\)

→

What for?

  • pressure in every node, flow in every edge
  • flows from the geometry instead of assumed flow values
  • input for the pharmacokinetic simulation

Poiseuille flow in one edge

Edge \(k = (i, j)\), flow from node \(i\) to node \(j\):

\[ q_k = c_k\,(p_i - p_j), \qquad c_k = \frac{\pi\, d_k^4}{128\,\mu\, l_k} \]

symbol meaning unit
\(p_i\) pressure at node \(i\) Pa
\(c_k\) hydraulic conductance L/(Pa·s)
\(\mu = 3.71\cdot10^{-3}\) blood viscosity Pa·s
\(d_k,\ l_k\) diameter, length mm
\(q_k\) volume flow L/s
  • pressures in Pa: tree pressures in mmHg are multiplied by MMHG_TO_PA \(=133.322\)
  • \(c \propto d^4\): halving the diameter → 16× less flow

compute_hydraulic_conductance(d, l) — the electric analogue: \(c\) = conductance, \(p\) = voltage, \(q\) = current.

Edges, groups and orientation

ODE groups (column ODE_groups)

code edge in the pressure system
0 marginal \((0,i)\) / \((i,0)\) boundary row (\(Q\) / outflow)
1 inner conservation row
2 preterminal, ends in a leaf leaf pressure → terminal row
3 terminal self-edge \((n,n)\) not used

Orientation: edges point in the direction of the flow

  • inflow (A, P): root edge \((0, i)\), flow splits towards the leaves
  • outflow (V, B): stored reversed, root edge \((i, 0)\), flow merges towards the outlet
  • node \(0\) is outside the tree → no column

numbers on the edges = ODE group; dashed = marginal edge, orange = leaves

Unknowns and the layout of the matrix

Unknowns \(x\): one pressure per node of every tree, then one inflow per inflow tree

\[ x = \big(\underbrace{p^{A}_1,\dots,p^{A}_{n_A}}_{\text{tree A}},\; \underbrace{p^{P}_1,\dots}_{\text{tree P}},\; \underbrace{p^{V}_1,\dots}_{\text{tree V}},\; \underbrace{p^{B}_1,\dots}_{\text{tree B}},\; Q_A,\; Q_P\big) \]

  • columns: tree \(t\) uses columns \(\text{col\_offset}_t + 1, \dots, \text{col\_offset}_t + n_t\), then the \(Q\) columns after all pressures
  • rows: tree \(t\) uses one row per edge, \(\text{row\_offset}_t + k\) for edge \(k\); boundary rows follow after all tree blocks
  • offsets grow tree by tree in the order of tree_info.vascular_trees

Inner edges of an inflow tree: flow splits

Edge \(k=(i,j)\in E_1\), successors \(s=(j,h)\in N^{+}(k)\)

flow into \(j\) = flow out of \(j\):

\[ c_k\,(p_i - p_j) \;=\; \sum_{s=(j,h)\in N^{+}(k)} c_s\,(p_j - p_h) \]

row \(\text{row\_offset}+k\), everything on the left:

\[ c_k\,p_i \;-\;\Big(c_k + \sum_s c_s\Big)\,p_j \;+\; \sum_s c_s\,p_h \;=\; 0 \]

the row of edge \(k\) is the conservation law at its end node \(j\) — add_equations!, is_inflow = true

Inner edges of an outflow tree: flow merges

Edge \(k=(i,j)\in E_1\), predecessors \(s=(g,i)\in N^{-}(k)\)

flow into \(i\) = flow out of \(i\):

\[ c_k\,(p_i - p_j) \;=\; \sum_{s=(g,i)\in N^{-}(k)} c_s\,(p_g - p_i) \]

row \(\text{row\_offset}+k\):

\[ \Big(c_k + \sum_s c_s\Big)\,p_i \;-\; c_k\,p_j \;-\; \sum_s c_s\,p_g \;=\; 0 \]

the row of edge \(k\) is the conservation law at its start node \(i\) — add_equations!, is_inflow = false

One function for both directions

Both rows have the same shape: own edge term + one term per neighbour. Only the shared node, the far node and one sign \(\sigma\) differ:

neighbours shared node far node of \(s\) \(\sigma\) coefficient of \(p_\text{far}\) coefficient of \(p_\text{shared}\)
inflow successors \((j,h)\) \(j\) \(h\) \(+1\) \(+c_s\) \(-c_s\)
outflow predecessors \((g,i)\) \(i\) \(g\) \(-1\) \(-c_s\) \(+c_s\)

\[ \text{row of } k:\qquad c_k\,p_i - c_k\,p_j \;+\; \sum_{s} \sigma\,c_s\,\big(p_{\text{far}(s)} - p_{\text{shared}}\big) \;=\; 0 \]

  • only group 1 edges get this row; rows of groups 0, 2, 3 stay empty here
  • the shared node collects several entries (\(-c_k\), \(-c_{s_1}\), \(-c_{s_2}\), …) → summed when the matrix is built
  • a neighbour that does not touch the shared node → @warn (consistency check of the table)

Inflow boundary: the unknown inflow \(Q_t\)

Root edge \(k_0=(0,i)\) of inflow tree \(t\) — node \(0\) has no pressure. The flow through it is a new unknown \(Q_t\):

\[ Q_t \;=\; \sum_{s=(i,h)\in N^{+}(k_0)} c_s\,(p_i - p_h) \]

\[ 1\cdot Q_t \;+\; \sum_s c_s\,p_h \;-\; \sum_s c_s\,p_i \;=\; 0 \]

  • written in the (otherwise empty) row \(\text{row\_offset}_t + k_0\)
  • column of \(Q_t\): after all pressure columns
  • the conductance of the root edge itself is not used

add_inflow_boundary! — one per inflow tree, exactly one marginal edge per tree

Outflow balance: all outflow = all inflow

Root edge \((i_t, 0)\) of outflow tree \(t\): its flow = flow from its predecessors into \(i_t\). One row for all trees:

\[ \sum_{t\,\in\,\text{out}}\;\sum_{s=(g,\,i_t)\in N^{-}(k_0^t)} c_s\,(p_g - p_{i_t}) \;-\; \sum_{t\,\in\,\text{in}} Q_t \;=\; 0 \]

  • every outflow tree writes into the same row, the entries are summed
  • \(-Q_t\) is pushed once per inflow tree
  • the root edge (conductance, node \(0\)) never enters the matrix
  • row: first row after all tree blocks

add_outflow_boundary! — called after the loop over the trees, with the stored column offset of each tree

Pressure drops between the trees

Root nodes: \(r_t\) = real node of the marginal edge (marginal_node)

Only a spanning set of (inflow, outflow) pairs: first inflow with every outflow, first outflow with every other inflow → \(n_\text{in}+n_\text{out}-1\) rows:

\[ p_{r_a} - p_{r_b} \;=\; \big(P_a - P_b\big)\cdot 133.322 \qquad a\in\text{in},\ b\in\text{out} \]

Common terminal pressure

Leaves \(L\) = end nodes of all preterminal (group 2) edges, all trees:

  • inflow edge \((i, j)\) → leaf \(j\)
  • outflow edge \((i, j)\) (reversed) → leaf \(i\)

All leaves have the same pressure — no matching of terminals between trees:

\[ p_{\ell_1} - p_{\ell} \;=\; 0 \qquad \forall\, \ell \in L\setminus\{\ell_1\} \]

  • \(|L| - 1\) rows, right side \(0\)
  • only the tree .arrow tables are used (no T.arrow, no synch_idx)
  • the whole capillary bed acts as one node

Absolute pressure: fix \(p_1\) of tree A

All rows so far contain only differences → \(p \to p + C\) is a null vector. One more row fixes the level:

\[ p^{A}_1 \;=\; P_A \cdot 133.322 \;=\; 80 \cdot 133.322 \;=\; 10\,666\ \text{Pa} \]

  • node 1 of tree A: column \(\text{col\_offset}_A + 1\), one entry \(+1\), right side in Pa
  • written after the terminal rows
  • with it every pressure is fixed by the pressure drops, so the other three root pressures follow

Challenges

Challenges: model and numerics

One common terminal pressure

  • all leaves of all trees are one node → the capillary bed has no resistance
  • terminals cannot differ in pressure → flow distribution only from tree geometry
  • first result (quad): leaf pressure 10.45 mmHg > P root 10 mmHg → flow in P is reversed
  • alternative: leaf pressure per tree → \(T-1\) rows fewer, closed with flow splits + total flow (see counting)

Conditioning

  • \(c \propto d^4\): diameters over 2–3 orders of magnitude → \(c\) over 8–12 orders
  • mixed units in one matrix: \(c\) (L/(Pa·s)), \(\pm1\) rows, Pa on the right side
  • → scale rows / unknowns (e.g. pressures in mmHg, \(c\) normalised) before a direct solve

Size and solver

  • \(N \sim 10^6\) nodes per tree → sparse LU (A \ b, UMFPACK) is fine in memory, but slow to build if not compacted
  • trees are acyclic: pressures can be computed tree by tree (resistances add up) in \(O(N)\) — a check for the matrix solution
  • validation: \(Q_A : Q_P \approx 1 : 3\) (physiology), mass balance \(\sum Q_\text{in} = \sum Q_\text{out}\)
